# authentication Specification

## MODIFIED Requirements

### Requirement: Browser-based SharePoint SSO and MFA capture
`SharepointBrowserAuth` in `src/idat_sync/infrastructure/sharepoint_auth.py` SHALL accept `(sharepoint_host: str, sharepoint_personal_host: str, email_domain: str)` without defaults. `fetch_storage_state(username, password, get_mfa_code)` SHALL launch Chromium with `await p.chromium.launch(headless=False, channel=channel)` and `timeout = 60000 * 3`, drive `async_playwright` through SharePoint, Microsoft SSO, and MFA, fill `#i0116` with `username` verbatim when `"@"` is present or `f"{username}@{email_domain}"` when `"@"` is absent, select the second MFA proof option via `await page.click("#idDiv_SAOTCS_Proofs > div:nth-child(2)")`, submit the OTP code from `await get_mfa_code()` via `#idTxtBx_SAOTCC_OTC`, `#idChkBx_SAOTCC_TD`, and `#idSubmit_SAOTCC_Continue`, wait for `https://login.microsoftonline.com/common/SAS/ProcessAuth` (`timeout=timeout`), call `await page.wait_for_selector("#skipMfaRegistrationLink, #KmsiCheckboxField", timeout=timeout)`, check `if await page.is_visible("#skipMfaRegistrationLink"):` and call `await page.click("#skipMfaRegistrationLink")` only when `True` (and MUST NOT click `#skipMfaRegistrationLink` when `False`) before calling `await page.click("#KmsiCheckboxField")` and `await page.click("#idSIButton9")`, wrap `async_playwright()` startup, `launch()`, `new_context()`, and page actions inside `try ... except Exception:` returning `None` while cleaning up any created `context` and `browser` in nested `try ... finally:` (so `browser.close()` runs even if `context.close()` raises) without swallowing `asyncio.CancelledError`, and return `StorageStateData | None`. Verified at the `SharepointBrowserAuth` seam.

#### Scenario: Completing Playwright SharePoint SSO and MFA flow
- **WHEN** `SharepointBrowserAuth(...).fetch_storage_state("jdoe", "pw", get_mfa_code)` or `fetch_storage_state("jdoe@other.edu", "pw", get_mfa_code)` runs with `page.is_visible("#skipMfaRegistrationLink")` returning `True` vs `False`
- **THEN** it launches with `headless=False`, visits `https://{sharepoint_host}/_layouts/15/sharepoint.aspx`, fills `"jdoe@{email_domain}"` when `"@"` is absent or `"jdoe@other.edu"` verbatim when `"@"` is present, fills password, clicks `"#idDiv_SAOTCS_Proofs > div:nth-child(2)"`, submits the code from `await get_mfa_code()`, waits for `"https://login.microsoftonline.com/common/SAS/ProcessAuth"` and `"#skipMfaRegistrationLink, #KmsiCheckboxField"` with `timeout = 60000 * 3`, clicks `"#skipMfaRegistrationLink"` before `"#KmsiCheckboxField"` and `"#idSIButton9"` when `is_visible("#skipMfaRegistrationLink")` is `True` and MUST NOT click `"#skipMfaRegistrationLink"` when `False`, visits `https://{sharepoint_personal_host}/shared`, and returns `await context.storage_state()`

#### Scenario: Swallowing browser startup and runtime exceptions while preserving cleanup and cancellation
- **WHEN** `async_playwright()`, `launch()`, `new_context()`, `context.close()`, or page interactions raise a runtime `Exception` vs `asyncio.CancelledError`
- **THEN** `fetch_storage_state` closes any created `context` and still closes any created `browser` even if `context.close()` raises, returns `None` on `Exception`, and propagates `asyncio.CancelledError`
