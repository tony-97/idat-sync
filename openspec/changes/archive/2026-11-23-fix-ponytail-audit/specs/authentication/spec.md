## MODIFIED Requirements

### Requirement: Application-owned authentication orchestration and pure-Python ports
`AuthService` in `src/idat_sync/application/auth_service.py` SHALL accept `(moodle_auth: MoodleTokenPort, sharepoint_auth: SharepointAuthPort, credential_store: CredentialStorePort)` without `SyncConfig`, URL/host strings, or `session_file`. `MoodleTokenPort.fetch_token(username, password) -> str`, `SharepointAuthPort.fetch_storage_state(username, password, get_mfa_code) -> StorageStateData`, and `AuthService.login(username, password, get_mfa_code) -> None` SHALL be `async def` coroutines, and `CredentialStorePort.save(credentials: Credentials) -> None` SHALL return `None` and raise `CredentialStoreError` on failure. `AuthService` MUST NOT define `authenticate`. `application/ports.py` SHALL define `CookieData`, `StorageStateData`, `Credentials`, `MoodleTokenPort`, `SharepointAuthPort`, and `CredentialStorePort` and re-export `IDATSyncError`, `AuthenticationError`, `CredentialsExpiredError`, `CredentialStoreError`, `RemoteServiceError`, and `FileSystemError` from `application/exceptions.py` with zero `playwright`, `tkinter`, `async_tkinter_loop`, `webview`, `jnius`, `requests`, or `httpx` imports. `AuthService.login` SHALL compute `moodle_username = username.split("@", 1)[0]` once, execute `self.moodle_auth.fetch_token(moodle_username, password)` and `self.sharepoint_auth.fetch_storage_state(username, password, get_mfa_code)` concurrently inside `asyncio.TaskGroup()`, catch `except* IDATSyncError as eg: raise eg.exceptions[0] from eg` (cancelling the incomplete sibling task immediately when either fails), raise `AuthenticationError` if either returns an empty token or storage state, persist `Credentials` via `await asyncio.to_thread(credential_store.save, credentials)`, and log completion using `moodle_username`. Verified at the `AuthService` (`src/idat_sync/application/auth_service.py`) and AST (`src/idat_sync/application/ports.py`, `src/idat_sync/application/exceptions.py`) seams.

#### Scenario: Normalizing username and running login providers concurrently
- **WHEN** `await AuthService.login(username, password, get_mfa_code)` is called with `"jdoe@custom.edu"` and `AuthService` is inspected
- **THEN** `hasattr(AuthService, "authenticate")` is `False`, `login` strips `"@..."` once into `moodle_username = "jdoe"` for `moodle_auth.fetch_token("jdoe", password)` and logging, passes the unsplit `"jdoe@custom.edu"` to `sharepoint_auth.fetch_storage_state("jdoe@custom.edu", password, get_mfa_code)` as named tasks inside `asyncio.TaskGroup()` without wrapping `moodle_auth.fetch_token` in `asyncio.to_thread`, saves `Credentials` via `asyncio.to_thread(credential_store.save, credentials)` only when both return non-empty results, and returns `None`

#### Scenario: Cancelling sibling login provider immediately and unwrapping TaskGroup errors
- **WHEN** either `moodle_auth.fetch_token` or `sharepoint_auth.fetch_storage_state` raises an `IDATSyncError` subclass (such as `AuthenticationError` or `RemoteServiceError`) while the sibling task is still pending, or returns an empty token or empty storage state, or `credential_store.save` raises `CredentialStoreError`
- **THEN** `asyncio.TaskGroup()` cancels the incomplete sibling task immediately, `AuthService.login` unwraps `except* IDATSyncError as eg: raise eg.exceptions[0] from eg` (raising `AuthenticationError` on empty provider output or `CredentialStoreError` on save failure) without saving invalid `Credentials`, and non-`IDATSyncError` failures still cancel the sibling and propagate

#### Scenario: Delegating logout, authentication check, and credential retrieval
- **WHEN** `logout()`, `is_authenticated()`, and `get_credentials()` are called on `AuthService`
- **THEN** `logout()` calls `credential_store.clear()`, `get_credentials()` returns `credential_store.load()`, and `is_authenticated()` returns `credential_store.load() is not None`

#### Scenario: Omitting unused login_flow_ended event parameter
- **WHEN** `AuthService.login` and `SharepointAuthPort.fetch_storage_state` signatures are inspected
- **THEN** neither accepts `login_flow_ended`

### Requirement: Browser-based SharePoint SSO and MFA capture
`src/idat_sync/config.py` SHALL define the shared `WEBVIEW_USER_AGENT = "Mozilla/5.0 (Linux; Android 14; SM-A556E) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/131.0.0.0 Mobile Safari/537.36"` constant and `is_android() -> bool` helper (returning `True` when `"ANDROID_ARGUMENT"` or `"ANDROID_BOOTLOGO"` is present in `os.environ`). `src/idat_sync/infrastructure/sharepoint_auth.py` SHALL define `WebViewDriver(Protocol)` exposing `async def goto(self, url: str) -> None`, `async def get_url(self) -> str`, `async def evaluate_js(self, script: str) -> Any`, `async def get_cookies(self) -> list[CookieData]`, and `async def aclose(self) -> None`, along with concrete adapters `PyWebviewDriver` and `AndroidWebViewDriver`. `SharepointBrowserAuth` SHALL accept `(sharepoint_host: str, sharepoint_personal_host: str, email_domain: str, driver: WebViewDriver)` where all four parameters are required. `fetch_storage_state(username, password, get_mfa_code)` SHALL poll `self.driver` at `_POLL_INTERVAL_S = 0.15` with `_TIMEOUT_S = 180.0`, visiting `https://{sharepoint_host}/_layouts/15/sharepoint.aspx`, waiting for `https://login.microsoftonline.com/**`, filling `#i0116` (via Knockout-compatible `HTMLInputElement.prototype.value` setter + bubbling `input` and `change` events) with `username` verbatim when `"@"` is present or `f"{username}@{email_domain}"` when `"@"` is absent and clicking `#idSIButton9`, filling `#i0118` with `password` and clicking `#idSIButton9`, waiting for `https://login.microsoftonline.com/*/login`, waiting for `#idTxtBx_SAOTCC_OTC, #idDiv_SAOTCS_Proofs [data-value="PhoneAppOTP"], #idDiv_SAOTCS_Proofs [data-value="OneWaySMS"]` without hardcoding `nth-child(2)`, skipping proof-row selection when `#idTxtBx_SAOTCC_OTC` is already visible, otherwise clicking `#idDiv_SAOTCS_Proofs [data-value="PhoneAppOTP"]` when visible or falling back to clicking `#idDiv_SAOTCS_Proofs [data-value="OneWaySMS"]`, raising `AuthenticationError("MFA code is required", reason="mfa")` without filling `#idTxtBx_SAOTCC_OTC` when `(await get_mfa_code()).strip()` is empty, otherwise filling `#idTxtBx_SAOTCC_OTC` with the stripped MFA code and clicking `#idChkBx_SAOTCC_TD` and `#idSubmit_SAOTCC_Continue`, waiting for `https://login.microsoftonline.com/common/SAS/ProcessAuth` and selector `#skipMfaRegistrationLink, #KmsiCheckboxField` (clicking `#skipMfaRegistrationLink` if visible, then clicking `#KmsiCheckboxField` and `#idSIButton9`), waiting for `https://{sharepoint_host}/_layouts/15/sharepoint.aspx` and host auth cookies before navigating to `https://{sharepoint_personal_host}/shared` and capturing personal host auth cookies, merging both cookie lists deduplicated by `(domain, path, name)`, always awaiting `await driver.aclose()` in `finally:`, logging via `logging.getLogger(__name__).exception(...)` and translating `TimeoutError` into `AuthenticationError("SharePoint sign-in timed out.", reason="timeout") from exc` and any other non-`AuthenticationError` runtime `Exception` into `AuthenticationError("SharePoint browser authentication failed", reason="sharepoint") from exc`, and propagating `asyncio.CancelledError` without swallowing it. Verified at the `SharepointBrowserAuth`, `PyWebviewDriver`, `AndroidWebViewDriver` (`src/idat_sync/infrastructure/sharepoint_auth.py`), and `bootstrap.create_auth_service` (`src/idat_sync/bootstrap.py`) seams.

#### Scenario: Completing Playwright SharePoint SSO and MFA flow
- **WHEN** `SharepointBrowserAuth(...).fetch_storage_state("jdoe", "pw", get_mfa_code)` runs vs `fetch_storage_state("jdoe@other.edu", "pw", get_mfa_code)`
- **THEN** it visits `https://{sharepoint_host}/_layouts/15/sharepoint.aspx`, fills `"jdoe@{email_domain}"` when `"@"` is absent or `"jdoe@other.edu"` verbatim when `"@"` is present into `#i0116`, fills `password` into `#i0118`, waits for `#idTxtBx_SAOTCC_OTC, #idDiv_SAOTCS_Proofs [data-value="PhoneAppOTP"], #idDiv_SAOTCS_Proofs [data-value="OneWaySMS"]` without `nth-child(2)`, fills the stripped code from `await get_mfa_code()` into `#idTxtBx_SAOTCC_OTC`, clicks `#idChkBx_SAOTCC_TD` and `#idSubmit_SAOTCC_Continue`, optionally clicks `#skipMfaRegistrationLink` when visible before `#KmsiCheckboxField` and `#idSIButton9`, captures host auth cookies after returning to `site_url` and after visiting `https://{sharepoint_personal_host}/shared`, merges cookies deduplicated by `(domain, path, name)`, closes the driver in `finally:`, and returns `StorageStateData`

#### Scenario: Selecting PhoneAppOTP before OneWaySMS or skipping proofs when OTP input is visible
- **WHEN** `SharepointBrowserAuth(...).fetch_storage_state(...)` reaches `https://login.microsoftonline.com/*/login` with (a) `#idTxtBx_SAOTCC_OTC` already visible, (b) both `data-value="PhoneAppOTP"` and `data-value="OneWaySMS"` visible in `#idDiv_SAOTCS_Proofs`, or (c) only `data-value="OneWaySMS"` visible
- **THEN** case (a) clicks no proof row and proceeds directly to OTP entry, case (b) clicks `#idDiv_SAOTCS_Proofs [data-value="PhoneAppOTP"]`, case (c) clicks `#idDiv_SAOTCS_Proofs [data-value="OneWaySMS"]`, and none of the cases query `nth-child(2)`

#### Scenario: Launching WebKit on macOS and Chromium channels on Windows and Linux
- **WHEN** `bootstrap.create_auth_service(config)` runs with and without `"ANDROID_ARGUMENT"` / `"ANDROID_BOOTLOGO"` in `os.environ`, or `await get_mfa_code()` returns `""` or whitespace during `fetch_storage_state`
- **THEN** `bootstrap.create_auth_service(config)` wires `AndroidWebViewDriver` on Android and `PyWebviewDriver` on desktop platforms into `SharepointBrowserAuth`, and a blank MFA code raises `AuthenticationError("MFA code is required", reason="mfa")` without filling `#idTxtBx_SAOTCC_OTC` while still awaiting `driver.aclose()`

#### Scenario: Swallowing browser startup and runtime exceptions while preserving cleanup and cancellation
- **WHEN** `driver.goto()`, `driver.evaluate_js()`, `driver.get_cookies()`, or `driver.aclose()` raises `TimeoutError`, another runtime `Exception`, or `asyncio.CancelledError`
- **THEN** `fetch_storage_state` always awaits `driver.aclose()`, logs runtime failures with traceback via `logging.getLogger("idat_sync.infrastructure.sharepoint_auth")` at `ERROR` level, raises `AuthenticationError("SharePoint sign-in timed out.", reason="timeout") from exc` on `TimeoutError` or `AuthenticationError("SharePoint browser authentication failed", reason="sharepoint") from exc` on other `Exception`s, and propagates `asyncio.CancelledError` even if `driver.aclose()` raises during cancellation cleanup
