# Spec Delta

## MODIFIED Requirements

### Requirement: Composition root wiring and UI decoupling for authentication
`create_auth_service(config: SyncConfig) -> AuthService` in `src/idat_sync/bootstrap.py` SHALL wire `MoodleTokenAdapter(MoodleTokenClient(config.moodle_base_url))`, `SharepointBrowserAuth(config.sharepoint_host, config.sharepoint_personal_host, config.email_domain, driver=AndroidWebViewDriver() if is_android() else PyWebviewDriver())`, and `JsonCredentialStore(config.session_file)` using `config` fields. `src/idat_sync/ui/` MUST NOT import `idat_sync.infrastructure`, `tkinter`, `async_tkinter_loop`, or `playwright`; `src/idat_sync/ui/dialogs.py`, `src/idat_sync/ui/icons.py`, and `src/idat_sync/ui/mfa_dialog.py` MUST NOT exist; `LoadingDialog` and `Icons` MUST NOT be exported in `src/idat_sync/ui/__init__.py`; `src/idat_sync/ui/index.html` SHALL exist as a self-contained single-file HTML bundle compiled from `frontend/` via Vite + SolidJS + Tailwind CSS + `vite-plugin-singlefile` per ADR-0008 (with zero Node.js runtime or external CDN stylesheet dependencies); `AppFrame` in `src/idat_sync/ui/base.py` (re-exported from `src/idat_sync/ui/app.py`) SHALL be a pure-Python base component class that MUST NOT define `exit` and SHALL define `async def aclose(self) -> None` and `@contextlib.asynccontextmanager async def _busy(self, set_flag: Callable[[bool], None])`; `MainApp` in `src/idat_sync/ui/app.py` SHALL accept `(config: SyncConfig, window: Any | None = None)`, own `self.loop = asyncio.new_event_loop()`, switch between `LoginFrame` and `SyncFrame`, create desktop windows with default size `width=1100, height=720`, expose `get_state() -> dict[str, Any]`, `push_state() -> None` (calling `window.evaluate_js` with `window.__onPythonState(...)` when `window` is attached), `push_progress(payload: dict[str, Any]) -> None` (calling `window.evaluate_js` with `window.__onFileProgress(...)` when `window` is attached), `pick_folder() -> str` (using the attached window's desktop folder dialog when available, returning `""` on cancellation, and falling back to `Path(os.environ.get("EXTERNAL_STORAGE", "/storage/emulated/0")) / "Download" / "idat-sync"` on Android or when no desktop folder dialog is available), and `async def on_close(self) -> None` (guarding against duplicate calls, awaiting `await self._frame.aclose()` when `self._frame` is non-`None`, and destroying any attached `window` in `finally:`); and `MainApp`, `LoginFrame`, and `SyncFrame` SHALL consume `AuthService`, `Credentials`, and `IDATSyncError` (with structured `reason`, `service`, `operation`, `status_code`, and `is_network` metadata) via `bootstrap` and `application`. `LoginFrame` in `src/idat_sync/ui/login_frame.py` SHALL keep `can_login` `False` whenever trimmed `username` is blank, `password` is empty, or authentication is in progress (`is_login`), track its active login task via `_busy` and cancel/await it in `async def aclose(self) -> None`, manage MFA prompts via an internal `asyncio.Future[str]` in `async def get_mfa_code(self) -> str` (resolved by `submit_mfa(code: str)` or `cancel_mfa()` with `""`, and cleaning up the MFA prompt state in `finally:` even when cancelled) without `get_mfa_code_ui`, initialize `error: str = ""` before calling `self.auth.logout()` wrapped in `try ... except CredentialStoreError as exc:` (recording `format_ui_error(exc)` in `self.error`), pass stripped `username` with verbatim `password` to `AuthService.login`, ignore blank or concurrent submissions, clear `self.error` when starting `do_login`, catch `IDATSyncError as exc` directly (logging raw `exc` via `_logger.error("Login error: %s", exc)` and setting `self.error = format_ui_error(exc)`), and reset `is_login` in `finally:`. Verified at the `bootstrap.create_auth_service`, `MainApp`, `AppFrame`, `LoginFrame`, `src/idat_sync/ui/index.html`, and AST (`src/idat_sync/ui/`) seams.

#### Scenario: Wiring AuthService from SyncConfig in bootstrap
- **WHEN** `create_auth_service(custom_config)` is called
- **THEN** it returns an `AuthService` wired with `MoodleTokenAdapter(MoodleTokenClient(custom_config.moodle_base_url))`, `SharepointBrowserAuth(custom_config.sharepoint_host, custom_config.sharepoint_personal_host, custom_config.email_domain, driver=...)` (with `AndroidWebViewDriver` on Android and `PyWebviewDriver` on desktop), and `JsonCredentialStore(custom_config.session_file)`

#### Scenario: Disabling Login on blank inputs or active login and guarding submissions
- **WHEN** `LoginFrame` initializes (including when `auth.logout()` raises `CredentialStoreError`), when trimmed `username` or raw `password` is empty vs. non-empty, or while `do_login` is running vs. completes/raises/switches frames via `MainApp.switch_to_sync()`
- **THEN** `LoginFrame.__init__` catches `CredentialStoreError` and records `format_ui_error(exc)` (`"Could not update stored credentials"`) in `self.error` without crashing startup, `can_login` starts `False` and becomes `True` only when trimmed `username`, non-empty `password`, and `not is_login` all hold, `do_login` ignores blank or concurrent submissions and passes stripped `username` with unstripped `password` to `AuthService.login`, `finally:` resets `is_login` to `False`, and `IDATSyncError` is caught directly without `ExceptionGroup` unpacking

#### Scenario: Displaying LoginFrame errors on False return and exceptions
- **WHEN** `do_login` starts with a pre-existing `error` message and `AuthService.login` raises `AuthenticationError` (with structured `reason`), `RemoteServiceError` (with structured `service`/`status_code`/`is_network`), or `CredentialStoreError`
- **THEN** `do_login` clears `self.error` on start, logs raw `exc` via `logging.getLogger("idat_sync.ui.login_frame").error(...)`, and stores the concise attribute-derived `format_ui_error(exc)` summary (never raw URLs, SDK tuples, or internal token/storage-state jargon) in `self.error`

#### Scenario: Submitting MFA via Return or dismissing MFA popup cleanly
- **WHEN** `await LoginFrame.get_mfa_code()` opens the MFA prompt (`mfa_open == True`) and `submit_mfa("654321")` is called, `cancel_mfa()` is called, or the awaiting task is cancelled
- **THEN** `hasattr(LoginFrame, "get_mfa_code_ui")` is `False`, `submit_mfa("654321")` resolves `get_mfa_code()` with `"654321"` and closes the MFA prompt (`mfa_open == False`), `cancel_mfa()` resolves `get_mfa_code()` with `""` and closes the MFA prompt, and cancelling `get_mfa_code()` resets `mfa_open` to `False` in `finally:` before propagating `asyncio.CancelledError`

#### Scenario: Enforcing UI isolation from infrastructure
- **WHEN** all Python modules under `src/idat_sync/ui/` are inspected
- **THEN** none import `idat_sync.infrastructure`, `tkinter`, `async_tkinter_loop`, or `playwright`, `src/idat_sync/ui/dialogs.py`, `src/idat_sync/ui/icons.py`, and `src/idat_sync/ui/mfa_dialog.py` do not exist, `"LoadingDialog"` and `"Icons"` are not in `idat_sync.ui.__all__`, `src/idat_sync/ui/index.html` exists and is non-empty, and `hasattr(AppFrame, "exit")` is `False`

#### Scenario: Closing active frame on WM_DELETE_WINDOW before destroying MainApp
- **WHEN** `await MainApp.on_close()` is triggered on a `MainApp` holding an active `LoginFrame` or `SyncFrame` (including while `do_login`, `load_idat_sync`, or `do_sync` is running)
- **THEN** `MainApp.on_close()` awaits `self._frame.aclose()` once (cancelling active frame tasks, closing open MFA futures and transports, and ignoring duplicate close triggers) before destroying the attached window in `finally:` even if `aclose()` raises

#### Scenario: Pushing structural state and targeted file progress from MainApp
- **WHEN** `MainApp.push_state()` and `MainApp.push_progress({"id": "file:1:a.pdf", "downloaded": 512, "total": 1024, "percent": 50, "speed_bps": 1024.0})` are called with an attached `window`, and `MainApp.run()` creates a desktop window
- **THEN** `push_state()` evaluates `window.__onPythonState(...)`, `push_progress(...)` evaluates `window.__onFileProgress(...)` with JSON-encoded payload, and `webview.create_window` receives `width=1100, height=720` and the bundled SolidJS `src/idat_sync/ui/index.html` containing no external CDN stylesheet links

### Requirement: Resilient SyncFrame recovery without silently wiping Credentials
`SyncFrame` in `src/idat_sync/ui/sync_frame.py` SHALL store injected `credentials`, track active startup (`load_idat_sync` / `retry_load`) and sync (`do_sync` / `sync_course`) tasks via `_busy`, expose `async def aclose(self) -> None` cancelling and awaiting any active task before closing and clearing `self.idat_sync` when present, expose `cancel_sync() -> None` cancelling only the active sync task without closing `self.idat_sync`, expose `set_folder_path(path: str) -> None` and `browse_folder() -> str` (delegating to `self.app.pick_folder()` and storing any non-empty returned path), raise `IDATSyncError("Sync service failed to initialize")` in `_ensure_sync_service` if `self.idat_sync is None` after creation, log any `IDATSyncError` raised during `_ensure_sync_service` once via `logging.getLogger(__name__).error(...)` before closing any newly constructed `self.idat_sync` (`await self.aclose()`) and re-raising, catch `IDATSyncError as exc` in `load_idat_sync`, `do_sync`, and `sync_course` to display concise summarized text in `self.status` and `self.error` via `_set_error_status` (setting `self.auth_expired = isinstance(exc, CredentialsExpiredError)`, storing `format_ui_error(exc)` on `CredentialsExpiredError` without a log-file hint and `f"{format_ui_error(exc)}. Check {self.config.log_file.name} for details."` on non-auth errors, and setting `self.status` to summarized text rather than raw `str(exc)`), reset `is_syncing` to `False` in `finally:`, retry `await create_sync_service(self.credentials, self.config)` in `retry_load`, `do_sync`, or `sync_course` whenever `self.idat_sync is None`, await `await self.aclose()` in `async def do_logout(self) -> None` before switching to login, and MUST NOT silently delete `Credentials` or auto-switch to `LoginFrame` on startup or sync errors. Verified at the `SyncFrame` (`src/idat_sync/ui/sync_frame.py`) seam.

#### Scenario: Recovering from a transient startup failure during Sync
- **WHEN** `await SyncFrame.load_idat_sync(credentials)` fails because `await create_sync_service(credentials, self.config)` raises an `IDATSyncError` (such as `RemoteServiceError("SharePoint error: ('500', '...')", service="SharePoint", status_code=500)`), leaving `self.idat_sync` as `None`, and the user later invokes `await retry_load()` or selects a folder and invokes `await do_sync()`
- **THEN** `_ensure_sync_service` logs the raw error once to `idat_sync.ui.sync_frame`, `load_idat_sync` writes the concise summary with `f"Check {self.config.log_file.name} for details."` into `self.error` and summarized text into `self.status` (without raw URLs or tuples), leaves `Credentials` intact on disk without switching frames, resets `is_syncing` to `False` in `finally:` (enabling `can_sync` once a folder is selected), and `retry_load()` or `do_sync()` retries `await create_sync_service(self.credentials, self.config)` when `self.idat_sync is None`

#### Scenario: Closing partial IDATSync transports when SyncFrame startup fails after service creation
- **WHEN** `create_sync_service(...)` succeeds in `load_idat_sync` or `_ensure_sync_service` and a subsequent step (`await idat_sync.list_courses()`) raises an `IDATSyncError`
- **THEN** `_ensure_sync_service` logs the raw error once, awaits `idat_sync.aclose()` before setting `self.idat_sync = None`, and keeps `Credentials` intact on disk

#### Scenario: Closing transports cleanly before switching to LoginFrame on Logout
- **WHEN** the user invokes `await SyncFrame.do_logout()`
- **THEN** `do_logout()` ignores the action if `self.is_syncing` is `True`, otherwise awaits `self.aclose()` (closing `self.idat_sync` and setting it to `None`) and invokes `self.app.switch_to_login()` in `finally:` even if `aclose()` raises

#### Scenario: Surfacing CredentialsExpiredError in SyncFrame without deleting stored Credentials
- **WHEN** `load_idat_sync`, `do_sync`, or `sync_course` catches `CredentialsExpiredError` (with or without `service`) or another `IDATSyncError`
- **THEN** `SyncFrame` stays active, sets `auth_expired == True` and writes the summarized `Credentials` message into `self.error` (without a log-file hint) and summarized status into `self.status` on `CredentialsExpiredError` (without re-logging a mid-sync `CredentialsExpiredError` already logged by `log_sync_event`), writes `f"{format_ui_error(exc)}. Check {self.config.log_file.name} for details."` into `self.error` on non-auth `IDATSyncError`, MUST NOT call `auth.logout()` or delete the credentials file, and resets `is_syncing` to `False` in `finally:`

#### Scenario: Cancelling active SyncFrame tasks cleanly on aclose
- **WHEN** `await SyncFrame.aclose()` runs while `load_idat_sync` or `do_sync` is in flight and `MainApp.on_close()` subsequently runs
- **THEN** `SyncFrame.aclose()` cancels and awaits the active task and closes `self.idat_sync` cleanly

#### Scenario: Cancelling an active sync via cancel_sync without closing IDATSync
- **WHEN** `SyncFrame.cancel_sync()` runs while `do_sync` or `sync_course` is in flight
- **THEN** only the active sync task is cancelled via `asyncio.CancelledError`, `self.idat_sync` remains open and reusable, `is_syncing` resets to `False`, and `self.status` becomes `"Sync cancelled."`
