# In-Progress Course Detection by Academic Term Category

We identify in-progress `Course` items in `domain/course.py` by parsing the `<YEAR>-<ROMAN><SUFFIX>` academic term suffix from `Course.category` (falling back to the leading token of `Course.name`) and selecting all courses matching the highest `(year, roman, suffix)` term across the enrolled course list. IDAT's Moodle instance sets `enddate = 0` on every course across all historical semesters and preserves stale `startdate` timestamps when cloning course templates, which causes Moodle's `core_course_get_enrolled_courses_by_timeline_classification(classification="inprogress")` endpoint to classify all past and current courses as in progress. Ranking the term code already present on `fetch_enrolled_courses` payloads isolates the active semester's courses in a single API call without per-course section or assignment queries on startup.
