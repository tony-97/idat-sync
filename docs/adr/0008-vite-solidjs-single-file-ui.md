# Vite + SolidJS Single-File Frontend Bundle

Supersedes the Astro frontend choice in ADR-0007 while preserving `pywebview`, the zero-Node-runtime single-file `src/idat_sync/ui/index.html` asset, and pure-Python testable UI controllers (`MainApp`, `AppFrame`, `LoginFrame`, `SyncFrame`, `CourseTree`). Because static Astro (`output: "static"`) compiles HTML once at build time without client-side reactivity, dynamic updates relied on vanilla JavaScript calling `replaceChildren()` on the entire course tree, which breaks down under streaming discovery, multi-pane layouts, and high-frequency download progress ticks (~6–7 updates/sec per active file). Replacing Astro with Vite, SolidJS (`createStore` + `reconcile` for structural snapshots and signal-backed updates for targeted `window.__onFileProgress(...)` events), Tailwind CSS, and `vite-plugin-singlefile` gives fine-grained DOM updates with zero virtual-DOM diffing while keeping the exact same self-contained single-file HTML packaging across Windows, macOS, Linux, and Android.
