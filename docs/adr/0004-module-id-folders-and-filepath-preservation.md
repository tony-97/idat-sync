# CourseModule ID Folders and Subfolder Path Preservation

Every `CourseModule` directory appends `-[<module.id>]` (truncating the sanitized module name first to stay within the 100-character segment limit) while preserving relative `ModuleContent` subfolder paths (`filepath`) under the module directory and disambiguating any remaining case-insensitive leaf path collisions in `IDATSync.get_course_remote_tree` (`stem (2).ext`, with `SyncDiff.from_trees` rejecting duplicates via `ValueError`). Reopening the nested path stability trade-off in ADR-0002 is safe now because no existing local course trees have been synced yet and this prevents distinct equal-named `CourseModule` items (such as duplicate `Rup` modules) as well as same-named files in different Moodle folder subdirectories from colliding silently. Top-level `Course` names, `CourseSection` names, and a retroactive local-folder migration script are kept unchanged and deferred until actually needed.
