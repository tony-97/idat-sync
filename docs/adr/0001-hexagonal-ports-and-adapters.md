# Hexagonal Ports and Adapters Architecture

We enforce strict inward dependency inversion across four packages (`ui/` and `infrastructure/` -> `application/` -> `domain/`), with object-graph wiring isolated in `bootstrap.py`. `application/` defines Driven Ports (`application/ports.py`) and performs pure use-case orchestration without importing `infrastructure/` or vendor SDKs, while vendor-specific HTML generation, assignment attachment merging, and SharePoint recording week projection are handled inside `infrastructure/` adapters (`MoodleAdapter`, `SharepointApiAdapter`) and pure tree-diff math lives on `SyncDiff.from_trees` in `domain/`. This keeps the core synchronization and curriculum logic testable in memory and completely decoupled from HTTP clients, browser automation, and filesystem I/O.
