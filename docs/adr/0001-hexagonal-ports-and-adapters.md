# Hexagonal Ports and Adapters Architecture

We enforce strict inward dependency inversion across four packages (`ui/` and `infrastructure/` -> `application/` -> `domain/`), with object-graph wiring and logging configuration isolated in `bootstrap.py`. `application/` defines Driven Ports (`application/ports.py`), publishes immutable sync lifecycle events (`application/events.py`) via constructor-injected publishers rather than imperative callback listeners, and performs pure use-case orchestration without `print()` statements or imports from `infrastructure/` or vendor SDKs. Vendor-specific HTML generation, assignment attachment merging, and SharePoint recording week projection are handled inside `infrastructure/` adapters (`MoodleAdapter`, `SharepointApiAdapter`) and pure tree-diff math lives on `SyncDiff.from_trees` in `domain/`, keeping core synchronization and curriculum logic testable in memory and completely decoupled from HTTP clients, browser automation, and filesystem I/O.
